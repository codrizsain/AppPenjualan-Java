# 🛒 Aplikasi Penjualan Ringan – Java (NetBeans IDE)

> Aplikasi kasir desktop sederhana berbasis Java Swing untuk pencatatan transaksi, pengelolaan data barang, dan studi kasus pemrograman Java.

---

## 📌 Tentang Proyek

Repository ini berisi proyek **Aplikasi Penjualan Ringan** yang dibangun menggunakan **Java** dan **NetBeans IDE**. Aplikasi ini menggunakan antarmuka **Java Swing**, sehingga mudah dipahami dan cocok untuk pembelajaran dasar pembuatan aplikasi desktop.

Proyek ini dirancang untuk membantu proses pencatatan transaksi sederhana, mulai dari pengelolaan data barang, input jumlah pembelian, perhitungan total otomatis, hingga menampilkan nota ringkas. 

Struktur kode dibuat sesederhana mungkin agar mudah dipelajari oleh mahasiswa, pemula Java, maupun pengembang yang ingin memahami logika dasar sistem penjualan. Aplikasi ini juga mendukung integrasi ke **MySQL** untuk pengembangan lanjutan.

---

## ✨ Fitur & Keunggulan

- 📦 **Pengelolaan Data Barang** — Menambah dan mengelola data produk/barang.
- 🧮 **Perhitungan Otomatis** — Menghitung total harga transaksi secara otomatis berdasarkan input jumlah pembelian.
- 🧾 **Nota Ringkas** — Menampilkan ringkasan nota transaksi.
- 💻 **Antarmuka Java Swing** — Tampilan GUI yang simpel, ringan, dan mudah dipahami.
- 🗄️ **Dukungan MySQL** — Dapat diintegrasikan ke sistem database untuk penyimpanan data lanjutan.
- 📚 **Media Pembelajaran** — Cocok untuk tugas, studi kasus GUI, hingga dasar pembuatan aplikasi kasir mini.

---

## 🛠️ Teknologi yang Digunakan

- **Bahasa Pemrograman:** Java
- **IDE:** NetBeans IDE
- **GUI Framework:** Java Swing
- **Database:** MySQL *(Opsional / Pengembangan Lanjutan)*
